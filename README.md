# SoloPreneur

Сайт Данила Тихонова: AI-функции для онлайн-школ и сквозная автоматизация процессов
для бизнеса, где работа идёт руками.

## Локальная работа

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
npm run check      # типы
npm run build
npm run preview
npm run markers    # что осталось незаполненным
```

## Контент

- `src/data/config.ts` — единственный источник констант: контакт, цены, счётчики,
  идентификатор счётчика Метрики. Меняется здесь — применяется везде.
- `src/data/site.ts` — шесть услуг, общий FAQ. Реэкспортирует `site` из конфига.
- `src/data/cases.ts` — кейсы. Полные (`depth: 'full'`) и одной строкой (`depth: 'brief'`).
  Скрытые (`hidden: true`) остаются доступными по адресу, но не попадают в списки,
  sitemap и поиск.
- `src/data/testimonials.ts` — отзывы.
- `src/pages/` — страницы и генераторы sitemap и robots.
- `src/styles/global.css` — общие стили. Стили отдельных блоков живут в самих компонентах.

## Незаполненные места

Цифры и отзывы, которых нет в подтверждённых материалах, отмечены прямо в тексте:
`[ЦИФРА: что нужно]` и `[ЗАПОЛНИТЬ: что нужно]`. На странице они видны как пометки,
а не как ошибка вёрстки. Найти все: `npm run markers`.

Выдуманных цифр, отзывов и названий клиентов на сайте нет — это осознанное правило.
Заменяйте маркер только тем, что готовы подтвердить.

Перед показом клиенту пометки можно скрыть: `flags.showMarkers = false` в `src/data/config.ts`.

## Аналитика

Счётчик Яндекс Метрики подключается, когда в `analytics.metrikaId` стоит номер больше нуля.
При нуле счётчик не загружается вообще. Клики по кнопкам связи размечены атрибутом
`data-goal` и отправляют цель `contact_click`.

Если включаете счётчик — проверьте, что описание на `/privacy/` соответствует тому,
что вы собираете.

## Публикация

Сайт живёт на Vercel и пересобирается сам при каждом push в `main` — отдельный
workflow не нужен. Сборка — `dist/`, настройки площадки — `vercel.json`.

Адрес сайта не захардкожен. На сборке он берётся из переменной Vercel
`VERCEL_PROJECT_PRODUCTION_URL`, локально — `http://localhost:4321`. От него
зависят canonical, sitemap, robots, og:image и идентификаторы в структурированных
данных, поэтому при переезде на свой домен достаточно задать в настройках проекта
Vercel переменную `PUBLIC_SITE_ORIGIN` (например `https://solopreneur.ru`) — в коде
менять нечего.

Сайт отдаётся с корня домена. Если когда-нибудь понадобится подпуть (например
GitHub Pages), добавьте `base` в `astro.config.mjs`: все внутренние адреса уже
собираются через хелпер `src/lib/url.ts` и подхватят префикс сами.

`netlify.toml` и `public/_headers` оставлены на случай переезда на Netlify;
на Vercel они не применяются, там действует `vercel.json`.

## Проверки перед публикацией

```sh
npm run check && npm run build
npm run markers
```

Мобильную вёрстку проверяйте на ширине 360px — основная часть посещений с телефона.
Горизонтальной прокрутки быть не должно ни на одной странице.

Сайт статический: нет базы данных, форм сбора, платных API и ключей в браузере.
Единственный внешний адрес для связи задан в `src/data/config.ts`.

Исходные документы в `Инфо/` исключены из Git и публикации.
