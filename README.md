# SoloPreneur

Русскоязычный сайт услуг Данила Тихонова: автоматизация процессов, Telegram-боты, AI/RAG и MVP.

## Локальная работа

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

## Контент

- `src/data/site.ts` — Telegram, адрес сайта, услуги, цены и FAQ.
- `src/data/cases.ts` — 14 кейсов. Количественные результаты без подтверждения не добавлены.
- `src/pages/` — страницы и генераторы sitemap/robots.
- `src/styles/global.css` — дизайн и адаптивность.
- `src/scripts/scene.ts` — 3D-схема Three.js с отложенной загрузкой и управлением анимацией.

Сайт полностью статический. Нет базы данных, форм сбора, рекламных трекеров, платных API и ключей в браузере. Контакт: https://t.me/Tikhonov_D.

## Публикация

Сборка: `dist/`. Идентификатор Sites сохранён в `.openai/hosting.json`. При обновлении переиспользовать этот сайт, не создавать новый.

Код переносим на статические хостинги; конфигурация Netlify — `netlify.toml`. При смене адреса обновить `site.origin`, пересобрать canonical, sitemap и robots, настроить перенаправления со старого адреса, когда это возможно.

Исходные документы `Инфо/` исключены из Git и публикации.

## Проверки перед публикацией

Проверены все 25 HTML-страниц, 23 адреса sitemap, внутренние ссылки, уникальность title и description, JSON-LD, мобильная главная и фильтры. На главной Lighthouse Mobile: accessibility 100, best practices 100, SEO 100. Замечание к доступному имени логотипа исправлено. Лабораторный trace главной (мобильный экран, Slow 4G, CPU ×4): LCP 1 418 мс, CLS 0.00. Это локальные измерения, не данные реальных посетителей. Эти показатели не являются гарантией ранжирования.

## Инструменты

Установлены отдельные skills: frontend-design, web-design-guidelines, seo-audit. Chrome DevTools MCP 1.9.0 установлен и проверен в работе, с временным профилем, без статистики и CrUX-запросов. Context7 зарегистрирован в Codex; первоначальная OAuth-авторизация не была завершена. Наличие списка инструментов не подтверждает доступ к авторизованным возможностям.

GitHub-плагин не является обязательным для запуска: исходники сохраняются в репозитории Sites. n8n и 21st.dev не являются зависимостями сайта.

## После запуска

Для наблюдения за поисковыми запросами и индексацией понадобится подтвердить сайт в собственных аккаунтах Яндекс Вебмастера и Google Search Console. Их проверочные токены не выдумываются и сейчас в сайт не добавлены. При появлении аналитики обновить страницу конфиденциальности.
